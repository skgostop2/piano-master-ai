# PIANO MASTER AI — 사용 설명서 · 테스트 결과 · 배포 방법

실제 소리가 나는 가상 피아노 + 10단계 초보자 학습 + 떨어지는 음표 + 악보 연습 + AI 연주 평가를 한 파일(PWA)로 만든 웹 프로그램입니다.
라이브러리 없이 Web Audio API · Web MIDI API · Canvas · localStorage만 사용하므로 빌드 과정이 없고, `deploy/` 폴더를 그대로 올리면 동작합니다.

## 1. 폴더 구성

## 2. 사용 설명서

### 시작
1. 페이지를 열면 "소리 켜고 시작하기" 버튼이 보입니다. 브라우저 정책상 첫 터치 뒤에 오디오가 켜지므로 이 버튼을 꼭 누르세요. (도·미·솔 소리가 나면 정상)
2. 휴대폰은 **가로모드**가 편합니다. 홈 화면 추가(iPhone: 공유 → 홈 화면에 추가 / Android: 메뉴 → 앱 설치)하면 전체화면 앱처럼 실행됩니다.
3. 처음에는 **초급** 메뉴(홈·피아노·기초 학습·떨어지는 음표·통계)만 보입니다. 통계·설정 → 수준을 **중급**으로 바꾸면 악보 연습·코드·AI 평가 메뉴가 열립니다.

### 점수 계산 근거 (AI 평가)
- 기준 악보의 각 음에 대해 같은 음정의 입력 중 **±300ms** 안에서 가장 가까운 것을 매칭합니다(입력 지연 보정값을 뺀 뒤 비교).
- **음정 정확도** = 매칭된 음 ÷ 전체 음 × (1 − 악보에 없는 입력 수 ÷ 2×전체 음)
- **리듬 정확도** = 매칭된 음의 평균 (1 − |시점 오차| ÷ 300ms)
- **음표 길이** = min(누른 시간, 악보 길이) ÷ max(…) 의 평균 (+15% 여유)
- **연주 타이밍** = 시점 오차의 평균(+는 늦음, −는 빠름)
- **반복 실수** = 같은 음을 2회 이상 놓침, 또는 한 마디에 오류 2개 이상
- **종합** = 음정 50% + 리듬 30% + 길이 20%

### 실제 피아노 연결
- **USB MIDI**: Chrome·Edge·Opera(Windows/Mac/Android)에서 작동. 통계·설정 → "MIDI 장치 검색". 연결되면 상단에 장치명이 표시되고 Velocity(세기)·서스테인 페달(CC64)을 인식합니다.
- **iPhone/iPad Safari, Firefox**: Web MIDI 미지원 → 화면 건반 또는 마이크 인식을 사용하세요.
- **마이크**: AI 평가 화면 → "마이크 켜기". 한 음씩 감지하며 신뢰도 90% 이상일 때만 판정합니다. 화음은 인식하지 않습니다.

## 4. 실행 및 배포

### 바로 실행
`deploy/index.html`을 더블클릭해도 실행됩니다(파일 열기). 단, 서비스워커·홈 화면 설치는 HTTPS에서만 됩니다.

### Netlify 배포(권장, 무료)
1. https://app.netlify.com → "Add new site" → "Deploy manually"
2. `deploy` 폴더를 통째로 드래그 앤 드롭
3. 발급된 주소(예: `https://xxxx.netlify.app`)를 휴대폰에서 열고 홈 화면에 추가

### GitHub Pages / 사내 서버
`deploy/` 내용을 루트에 올리면 됩니다. 경로가 하위 폴더면 `manifest.json`의 `start_url`/`scope`는 상대경로(`./`)라 그대로 동작합니다.

### 소스 수정
`src/` 파일을 고친 뒤 `python3 build.py` 실행 → `deploy/index.html`과 `piano-master-ai.html`이 다시 만들어집니다.

## 5. 기술 선정 이유
- 요구서의 React+TypeScript+Vite 대신 **순수 HTML/JS 단일 파일**로 만들었습니다. 이유: 빌드 없이 어디서나 실행·배포·수정이 가능하고, 오디오 지연에 프레임워크 오버헤드가 없으며, 클로드 아티팩트에도 그대로 게시됩니다. 추후 기능이 더 커지면 `src/` 구조를 그대로 Vite 프로젝트로 옮길 수 있습니다.
- **음원**: 라이선스가 확인된 피아노 샘플을 내장하는 대신 Web Audio 합성(배음 5개 + 해머 노이즈 + 저역 필터 + 잔향)을 사용했습니다. 저작권 문제가 없고 용량이 0입니다. 더 사실적인 음색이 필요하면 CC0/MIT 샘플(예: Salamander Grand Piano, CC BY 3.0)을 `Audio.noteOn`에 교체 연결하면 됩니다.
- **악보 렌더링**: VexFlow 같은 외부 라이브러리 대신 Canvas로 직접 그렸습니다(덧줄·#·점음표·꼬리·쉼표 지원). 복잡한 악보(잇단음표, 이음줄 등)가 필요하면 VexFlow(MIT) 도입을 권합니다.
- **저장**: localStorage에 `schema: 1`, `updatedAt`, `deviceId`를 포함한 하나의 JSON으로 저장합니다. Supabase 동기화 시 이 JSON을 그대로 upsert하면 됩니다.
